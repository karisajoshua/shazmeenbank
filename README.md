# 🌐 Shazmeen Bank Learning & Coaching Platform

Welcome to the official repository for the **Shazmeen Bank Learning & Coaching Platform**, a modern digital platform built using **React + Vite** to deliver transformative coaching, learning, and consulting services.

---

## 🎯 Project Objective

To redesign and digitize the Shazmeen Bank website into a sleek, interactive platform that enables:

- 📚 A full-featured Learning Management System (LMS)
- 📰 Newsletter subscriptions and campaigns
- 📅 Booking and scheduling of coaching sessions
- 🎙️ Podcast listening and sharing
- 👤 Personalized user dashboards for both learners and instructors

---

## ⚙️ Tech Stack

- **Frontend Framework:** React + Vite
- **CMS Options:** Headless CMS (e.g., Strapi or Sanity) or Firebase
- **Payment Integration:** Stripe, PayPal, Flutterwave, M-Pesa
- **Booking System:** Calendly API or custom booking logic
- **PDF Automation:** Social-to-Automation tools (e.g., ManyChat or Instagram DM automation)

---

## 🔑 Core Features

### 1. LMS (Learning Management System)

- Video, text, and quiz-based course creation
- Progress tracking & certification issuance
- Advanced course search & categorization
- Instructor & student dashboards

### 2. Coaching Bookings

- Book 1-on-1 sessions with calendar selection
- Time slot availability and confirmation system
- Payment and invoicing integration

### 3. Podcast Integration

- Embed or stream episodes from popular platforms
- Group podcasts by series or topics
- User-friendly interface for playback

### 4. Newsletter & Lead Capture

- Newsletter opt-in forms
- Integration with Mailchimp/ConvertKit
- PDF delivery automation based on keyword triggers on social media

### 5. Dashboard Modules

- **Admin:** Manage users, courses, bookings
- **Instructor:** Upload content, track learner progress
- **Student:** Access courses, download materials, track milestones
